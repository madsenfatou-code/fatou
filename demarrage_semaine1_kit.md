## ÉTAPE 2 — Votre Premier Prompt de Test (15 min)

Copiez-collez ce prompt dans Claude :

```
Tu es un expert en ingénierie de formation spécialisé dans les centres d'appels.
J'ai 15 ans d'expérience dans ce domaine : formation de formateurs et managers,
qualité des appels (chartes entrants/sortants/mailing), ISO 9001 v2015,
amélioration continue, soft skills, et recrutement.

Je souhaite intégrer l'IA dans mon activité freelance.

Fais-moi une analyse en 5 points : quelles sont les tâches concrètes de mon
quotidien professionnel où l'IA peut m'apporter le plus de valeur immédiatement,
et pourquoi ? Sois très précis et orienté "cas d'usage pratique".
```

**Notez la réponse dans votre journal Notion.**

## ÉTAPE 4 — Votre Formule de Prompt Magique

Mémorisez cette structure **RCTF** :

```
R — RÔLE    : "Tu es un expert en [domaine]..."
C — CONTEXTE : "Dans le cadre de [situation]..."
T — TÂCHE   : "Crée / Analyse / Rédige [livrable précis]..."
F — FORMAT  : "Sous forme de [tableau/liste/rapport/...]"
```

### Exemple appliqué à votre métier :
```
R — "Tu es un expert qualité en centres d'appels et formateur certifié ISO 9001."
C — "Un centre d'appels de 50 agents traite 500 appels/jour avec un taux de
     réclamation de 8%, soit 2 points au-dessus de la cible."
T — "Rédige un plan d'action d'amélioration continue sur 30 jours pour réduire
     ce taux à 6%."
F — "Format : tableau avec colonnes Action / Responsable / Délai / Indicateur de
     mesure. 8 à 10 actions maximum."
```

## ÉTAPE 5 — Votre Premier Livrable (45 min)

Rédigez ce prompt et sauvegardez le résultat :

```
Tu es un expert en formation professionnelle pour centres d'appels avec 15 ans
d'expérience.

Génère une grille d'évaluation qualité pour les appels entrants d'un service
client, basée sur les meilleures pratiques et compatible avec les exigences
ISO 9001 v2015 (satisfaction client, conformité, amélioration continue).

Format : tableau avec ces colonnes :
- Critère d'évaluation
- Description du comportement attendu
- Indicateur de non-conformité
- Pondération (sur 100 points total)
- Commentaires

Inclure les catégories : Accueil, Identification, Écoute active, Traitement de
la demande, Maîtrise des émotions, Conformité aux procédures, Conclusion.
```

**Ce livrable est déjà vendable. Félicitations pour votre premier livrable IA.**

## RESSOURCE BONUS — Les 5 Commandements de l'IA pour Formateurs

1. **"L'IA est un stagiaire brillant"** — Donnez-lui des instructions précises, vérifiez son travail, gardez votre expertise
2. **"Jamais de données personnelles réelles"** — RGPD : utilisez toujours des données fictives dans vos prompts
3. **"Itérez, ne capititulez pas"** — Si la réponse ne convient pas, reformulez, précisez, recommencez
4. **"Votre expertise reste la valeur ajoutée"** — L'IA produit vite, vous produisez juste
5. **"Un livrable IA = un point de départ"** — Toujours adapter, personnaliser, valider avec votre regard expert

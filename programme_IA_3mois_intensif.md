### SEMAINE 1 — Comprendre et Prendre Confiance

#### LUNDI — Jour 1 : Bienvenue dans l'IA

**Matin (2h)**
- Théorie 45 min : Qu'est-ce que l'IA générative ? LLM, tokens, paramètres — expliqués sans jargon. Regarder : "AI for Everyone" leçon 1 (Coursera, gratuit)
- Exercice 75 min : Créer vos 5 comptes (Claude, ChatGPT, Perplexity, Notion, Canva). Configurer votre journal de bord Notion avec le template ci-dessous

**Template journal Notion :**
```
DATE :
OUTIL UTILISÉ :
CE QUE J'AI PRODUIT :
MEILLEUR PROMPT :
CE QUI N'A PAS MARCHÉ :
DÉCOUVERTE DU JOUR :
NIVEAU CONFIANCE /10 :
```

**Après-midi (2h)**
- Production : Dialogue libre avec Claude 1h — posez-lui toutes vos questions métier (centres d'appels, ISO, formation). Observez comment il répond
- Production : Faire la même chose avec ChatGPT 30 min. Comparer les deux
- Livrable : Fiche comparative Claude vs ChatGPT — vos premières observations (Notion, 1 page)

---

#### MARDI — Jour 2 : La Formule Magique des Prompts

**Matin (2h)**
- Théorie 45 min : La méthode RCTF — Rôle, Contexte, Tâche, Format. C'est votre levier principal
- Exercice 75 min : Écrire 10 prompts en appliquant RCTF sur des sujets que vous connaissez par cœur (grilles qualité, plans de formation, emails managers)

**Méthode RCTF appliquée à votre métier :**
```
PROMPT TYPE :
"Tu es [expert qualité / formateur / consultant ISO].
Dans le contexte [centre d'appels / formation initiale / audit interne].
Crée [livrable précis avec détails].
Présente sous forme de [tableau / liste numérotée / rapport en sections]."
```

**Après-midi (2h)**
- Production : Générer votre première **grille d'évaluation qualité appels entrants** avec RCTF
- Production : L'améliorer 3 fois de suite en affinant le prompt à chaque itération
- Livrable : Grille QA appels entrants finale — Version 1 de votre portfolio

**Prompt à utiliser :**
```
Tu es un expert qualité en centres d'appels avec certification ISO 9001 v2015.
Dans le cadre du contrôle qualité d'un service client de 50 agents,
traitant 500 appels entrants par jour.
Crée une grille d'évaluation complète compatible ISO 9001 v2015.
Format : tableau avec colonnes Critère / Comportement attendu /
Non-conformité / Pondération (total 100 pts) / Zone commentaire.
Catégories : Accueil (15 pts) / Identification (10 pts) /
Écoute active (20 pts) / Traitement demande (25 pts) /
Gestion émotions (15 pts) / Conformité procédures (10 pts) /
Conclusion (5 pts).
```

# FICHE OBJECTIFS — FUNDRAISING UNICEF
> Référentiel opérationnel pour les fundraisers terrain et téléphone

---

## 1. INDICATEURS CLÉS DE PERFORMANCE (KPI)

### KPI 1 — Contact Utile (CU)

| Indicateur | Valeur |
|---|---|
| Objectif CU / heure | **9 contacts utiles** |
| Exemple de session | 22 contacts — 13 utiles |
| **Poids du CU** | **13 / 22 = 59%** |

> Un contact est dit "utile" dès lors qu'il dépasse **1 minute** d'échange réel avec le prospect.

---

### KPI 2 — Taux de Transformation (Concrétisation)

| Indicateur | Valeur |
|---|---|
| Objectif de concrétisation | **1%** |
| Taux de refus attendu | **99%** |
| Prélèvement Automatique (PA) moyen cible | **10 € / mois** |

> Le refus est la norme, pas l'exception. Chaque "non" bien géré est un investissement pour le suivant.

---

### KPI 3 — Modes de Paiement & Taux de Transformation

| Code | Libellé | Description |
|---|---|---|
| **DEL** | Don En Ligne | Don ponctuel via interface web |
| **PEL** | Paiement En Ligne | Règlement immédiat en ligne |
| **PA** | Prélèvement Automatique | Engagement mensuel récurrent |

**Qui saisit le paiement ?**
- Le **donateur** lui-même (autonomie)
- Le **fundraiser** (accompagnement guidé)

## 2. SCRIPT D'ACCROCHE — LE DÉCOLLAGE

> Le **décollage** est le moment critique où l'on crée le lien en **déconstruisant les anciennes habitudes** du prospect.

### Séquence d'appel

```
1. "Allô ?"          → Attendre le retour du prospect
2. Identifier le genre (M. / Mme)
3. Formule de politesse personnalisée : "Bonjour [Prénom/Nom]"
4. Se présenter : prénom + organisation (UNICEF)
5. Marquer la différence : pourquoi cet appel est différent
```

### Règle d'or
- Le contact **doit dépasser 1 minute** pour être comptabilisé comme CU
- Laisser **une bonne impression après chaque refus** — le prospect d'aujourd'hui est le donateur de demain

---

## 3. QUALIFICATION DES CONTACTS

| Code | Catégorie | Description |
|---|---|---|
| **DON** | Donation confirmée | Engagement obtenu — PA, DEL ou PEL |
| **IND** | Indécis | Intéressé mais non décidé — à relancer |
| **RA** | Refus Argumenté | Refus avec justification — à traiter avec empathie |

### Posture face au refus
- Ne jamais couper court
- Reformuler l'argument du refus pour montrer qu'on a entendu
- Conclure sur une note positive : image UNICEF préservée
- **Un RA bien géré = porte ouverte pour une future conversion**
